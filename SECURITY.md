# Security Policy

## Supported Versions

Security updates and patches are maintained for the latest active release branches:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within Wordle AI, please report it privately rather than creating a public issue.

### How to Report
- Email vulnerability details to: `security@wordle-ai.dev`
- Include a summary of the vulnerability, affected components, reproduction steps, and any proof of concept if available.

### Disclosure Policy & Response Timeline
- **Initial Response**: We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment & Triage**: Maintainers will evaluate the report, verify the impact, and coordinate remediation.
- **Resolution**: Once a security fix is prepared, an advisory and patch release will be published.
- **Coordinated Disclosure**: We ask reporters to allow 48 hours for acknowledgment and a reasonable window for remediation before public disclosure.
